Praca domowa 0001 · A1 · 10-15 minut

Rodzaj rzeczownika

Ćwiczysz formę podstawową oraz regularne wzorce rodzaju męskiego, żeńskiego i nijakiego.

Jak pracować

Zapisz wszystkie odpowiedzi przed otwarciem podpowiedzi. Wyślij mi odpowiedzi nieujawnione oraz całe zadanie 4. Możesz także wysłać każde miejsce, które było niejasne.

1. Forma podstawowa

Zapisz mianownik liczby pojedynczej. Odpowiedź ma zawierać tylko jeden rzeczownik.

  1. ogrody → ______
  2. lampy → ______
  3. mieszkania → ______
  4. komputery → ______
  5. ulice → ______
  6. muzea → ______
Sprawdź odpowiedzi 2 i 6

2. lampa. 6. muzeum. Forma mnoga może mieć zakończenie inne niż forma podstawowa.

2. Wybór rodzaju

Napisz M, Ż albo N, a potem podaj wskazówkę: spółgłoska, -a, -o, -e, -ę albo -um.

  1. chleb
  2. kawa
  3. krzesło
  4. pytanie
  5. tramwaj
  6. imię
  7. torba
  8. centrum
Sprawdź odpowiedzi 1, 4 i 8

1. M, spółgłoska. 4. N, -e. 8. N, -um.

3. Nowe słowa

Wstaw: otoczenie, sprzęt, dziedzina, wydarzenie albo wyjątek. Każdego słowa użyj raz.

  1. Komputery, monitory i drukarki to biurowy ______.
  2. Koncert jest dużym kulturalnym ______.
  3. Medycyna to trudna ______ wiedzy.
  4. Park i spokojne ______ domu są dla mnie ważne.
  5. Ta forma nie pasuje do reguły, więc jest to ______.
Sprawdź odpowiedzi 1 i 5

1. sprzęt. 5. wyjątek. W tych zdaniach forma zależy od konstrukcji, ale rozpoznajesz to samo słowo.

4. Popraw analizę

Każda analiza zawiera jeden problem. Napisz pełną poprawną analizę według wzoru: słowo → forma podstawowa → rodzaj → wskazówka.

Wzór: stoły → stół → męski → spółgłoska

  1. okna → okno → żeński → -a
  2. książki → książka → nijaki → -a
  3. telefony → telefon → męski → -y
  4. morza → morze → męski → -e
Sprawdź odpowiedź 4

4. morza → morze → nijaki → -e. Problemem był błędnie podany rodzaj.

5. Krótka produkcja

Wybierz trzy rzeczowniki z lekcji: jeden męski, jeden żeński i jeden nijaki. Napisz trzy krótkie, naturalne zdania. Pod każdym zdaniem podaj rodzaj użytego rzeczownika.
