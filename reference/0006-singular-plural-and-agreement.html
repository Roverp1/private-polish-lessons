Jedna rzecz, kilka rzeczy

Jak zmienić liczbę całego komunikatu, a nie tylko jednego wyrazu.

01Decyzja w czterech krokach

  1. Ustal liczbęJedna rzecz lub osoba: lp. Więcej niż jedna: lm.
  2. Utwórz rzeczownikUżyj znanego wzorca albo sprawdź w WSJP: liczba mnoga, M.
  3. Wybierz grupęone wskazuje dzisiejszą grupę niemęskoosobową.
  4. Sprawdź zgodęW lm.: są; przymiotnik niemęskoosobowy: -e/-ie.

02Identyfikacja i opis

CelLiczba pojedynczaLiczba mnoga
IdentyfikacjaTo jest telefon.To są telefony.
OpisTelefon jest nowy.Telefony są nowe.

03Cztery wzorce rzeczownika z lekcji

Lp.OperacjaLm.Drugi przykład
telefondodaj -ytelefonyprojektor → projektory
kawa-a → -ykawylampa → lampy
książkapo k: -a → -iksiążkikartka → kartki
okno / narzędzie-o/-e → -aokna / narzędziakrzesło → krzesła
Granica tabeli: inne słowa mogą mieć inny wzorzec, np. hotel → hotele, noc → noce, człowiek → ludzie. Nie zgaduj pewnie. Sprawdź formę M. liczby mnogiej.

04Zgoda niemęskoosobowa

Lp.Lm. niemęskoosobowaForma przymiotnika
nowy telefonnowe telefonynowe
nowa lampanowe lampynowe
nowe oknonowe oknanowe
krótka książkakrótkie książkipo k: -ie
droga torbadrogie torby-gi → -gie

Ta sama decyzja co przy zaimku

  • one: rzeczy, zwierzęta, same kobiety → niemęskoosobowa → nowe, gotowe;
  • oni: mężczyźni lub mieszana grupa osób → męskoosobowa → formy na później.
  • To skrót dla zwykłych grup; np. dzieci → one. Konkretna nazwa ma własną kategorię gramatyczną.

Kontrola całego zdania

Lampa jest droga.
↓ liczba mnoga
Lampy są drogie.

Sprawdź: rzeczownik + być + przymiotnik.
