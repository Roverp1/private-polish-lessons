Oni są gotowi

Jak wybrać grupę i zbudować podstawowy mianownik liczby mnogiej męskoosobowej.

01Decyzja w czterech krokach

  1. Nazwij grupęSprawdź konkretną nazwę albo osoby połączone przez i.
  2. Wybierz zaimekoni: męskoosobowa. one: niemęskoosobowa.
  3. Utwórz rzeczownikUżyj znanej rodziny albo sprawdź w WSJP: lm., M.
  4. Sprawdź zgodęsą + właściwa forma przymiotnika.

02Dwie grupy

GrupaZaimekPrzykładOpis
niemęskoosobowaoneAnna i Ewa; dzieci; telefonysą gotowe
męskoosobowaoniMarek i Piotr; Anna i Marek; pracownicysą gotowi
Granica skrótu: dzieci → one → gotowe, ale chłopcy → oni → gotowi. Liczy się gramatyczna nazwa grupy, nie tylko biologiczny skład.

03Trzy aktywne rodziny rzeczownika

ZmianaPrzykładDrugi przykład
-ent → -encistudent → studenciklient → klienci
-nik → -nicypracownik → pracownicyuczestnik → uczestnicy
-ca → -cysprzedawca → sprzedawcykierowca → kierowcy
Formy leksykalne: kolega → koledzy; pan → panowie; człowiek → ludzie; mężczyzna → mężczyźni. Zapamiętaj parę albo sprawdź ją w słowniku. Nie twórz z niej fałszywej reguły.

04Przymiotnik: aktywny zestaw

SłownikOniOneZmiana lub wskazówka
nowy / gotowynowi / gotowinowe / gotowe-y → -i
sprawny / obecnysprawni / obecnisprawne / obecne-ny → -ni
spóźnionyspóźnienispóźnionezapamiętaj parę
zajętyzajęcizajętet → ci

Rozpoznawaj: młody → młodzi; dobry → dobrzy; drogi → drodzy; wysoki → wysocy. Nie działa ślepe „-y → -i”.

Pełna zgoda

Pracownik jest sprawny.
↓ grupa
Pracownicy są sprawni.

Rzeczownik + są + przymiotnik.

Kontrast

Nowe koleżanki są gotowe.
Nowi koledzy są gotowi.

Anna i Ewa są obecne.
Anna i Marek są obecni.
