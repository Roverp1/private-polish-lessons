# Voice-led read-aloud workflow established

The learner selected a Polish-only, voice-led delivery workflow for grammar lessons. The learner uploads the HTML to ChatGPT Voice, reads each short section aloud, says `Skończyłem`, demonstrates understanding through explanation and transfer practice, then writes and reads back a checked notebook note. English is an explicit fallback only when Polish clarification fails; pronunciation correction is limited to errors that block meaning plus at most one recurring high-value issue per section.

This replaces the earlier assumption that speaking practice is separate from lessons or that the speaking tool is undecided. Future lessons must embed section-by-section teacher guidance, notes-allowed and closed-notes practice, a spoken task, and a final report that the learner returns to the main teacher. Lesson 1 exists but has not yet been completed, so this record establishes the method, not mastery of Polish cases.
