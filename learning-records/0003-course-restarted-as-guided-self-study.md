# Course restarted as guided self-study

The learner reported that the delegated voice lessons introduced grammar labels but did not teach the rules needed to solve their exercises. The new finite A1-B1 course therefore teaches explicit grammar from first principles in concise Polish pages, pairs every rule with immediate practice, and uses homework plus an unrevealed exit check as the normal submission.

Implications: prior voice-course classifications are exposure, not mastery or error evidence. The repository is authoritative, another model does not conduct lessons, and future pacing changes only in response to work demonstrated in this course.
