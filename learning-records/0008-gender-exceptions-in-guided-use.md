# Gender exceptions work when the noun is supplied

The learner correctly produced `pilna wiadomość`, `krótka odpowiedź`, `krótka noc`, `nowa osoba`, and `nowy kolega`, then used `kierowca` and `wiadomość` with correct agreement in a short message. This establishes agreement with the exception nouns supplied in Lesson 0005; it does not establish independent dictionary lookup or retrieval of an unfamiliar noun's gender, which should receive one later mixed check rather than more copying drills.

The learner found Lesson 0005 extremely easy and boring because gender labels and already-correct adjective forms removed the decisions, while the frontloaded notebook block made later explanations redundant. Future lessons must distribute optional notes, stop after representative evidence, use natural Polish beyond the assessed grammar, and make situated writing genuinely independent rather than disguised substitution.
